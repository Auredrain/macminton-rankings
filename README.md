# 羽毛球世界排名数据库

基于 BWF 官方公开数据与中羽在线（badmintoncn.com）构建的羽毛球排名数据可视化站点。

## 内容

- **5 个项目**：男单 / 女单 / 男双 / 女双 / 混双
- **1990–2026** 共 1,672 期世界排名（男单）/ 1,554 期（其余四项）
- 4,249 名球员、80,109 站赛事、61,439 场逐场比赛记录
- 交手记录、跨时代胜率推演、赛程资讯

## 部署

单文件站点，`index.html` 即全部内容（数据内嵌，无需后端）。

### GitHub Pages

1. 仓库 **Settings → Pages**
2. Source 选择 **Deploy from a branch**
3. Branch 选 `main`，目录选 `/ (root)`
4. 保存后访问 `https://<用户名>.github.io/<仓库名>/`

`.nojekyll` 已包含，避免 Jekyll 处理大文件。

### 其他平台

| 平台 | 操作 |
|---|---|
| Vercel | 导入仓库，无需构建命令，输出目录填 `.` |
| Netlify | 拖拽本目录到 Netlify Drop |
| Cloudflare Pages | 连接仓库，构建命令留空 |

## 数据来源

| 来源 | 用途 |
|---|---|
| BWF 官方 API | 当前排名、球员档案、赛事结果 |
| 中羽在线 | 历史排名、逐场比赛、球员资料 |

本站为非官方站点，数据仅供学习研究。资讯内容为本站基于事实自行撰写并标注来源，不转载原文。

## 说明

- 单个 HTML 约 21.7 MB，首次加载较慢
- 页面完全离线可用（数据内嵌，无外部依赖）
